<summary><b>For developers</b></summary>

Next.js 16 (App Router) · React 19 · Tailwind CSS · Vercel. Bilingual (ml-IN / en-IN), Instagram feed via the Meta Graph API, GA4 conversion events (`click_whatsapp`, `click_call`, with a `placement` parameter).

```bash
pnpm install
cp .env.example .env.local   # IG_TOKEN and Meta credentials
pnpm dev                     # http://localhost:9002
pnpm typecheck && pnpm build
```

The Instagram token is refreshed automatically on the 1st and 15th of each month by [`.github/workflows/refresh-instagram-token.yml`](.github/workflows/refresh-instagram-token.yml), which updates `IG_TOKEN` in every Vercel environment.
